# Runbook — Miscellaneous (Divers)

## Symptômes couverts
- Demande d'information générale sur les services informatiques
- Demande non classée dans les autres catégories
- Question sur les horaires du support informatique
- Demande de formation sur un outil logiciel
- Autre demande informatique non urgente

## Procédure de dépannage

1. **Analyser la demande** : lire attentivement la description pour identifier le besoin réel de l'utilisateur.
2. **Rechercher dans la base de connaissances** : vérifier si une procédure existe déjà pour ce type de demande.
3. **Orienter vers le bon contact** : si la demande relève d'un autre service (RH, Achats, Sécurité), transférer avec les informations nécessaires.
4. **Fournir l'information** : si c'est une question générale (horaires, procédures, contacts), répondre directement avec les ressources disponibles.
5. **Créer un ticket de suivi** : enregistrer la demande dans le système de ticketing pour traçabilité, même si elle est résolue immédiatement.
6. **Demander des précisions** : si la demande est trop vague, demander à l'utilisateur de préciser son besoin (système concerné, message d'erreur, étapes déjà tentées).

## Escalade
Si la demande s'avère complexe ou relève d'un domaine spécialisé, transmettre à l'équipe concernée avec un résumé clair (délai : selon priorité).

## Temps estimé
5 à 20 minutes.
